# HTML & CSS AMA Questions and Answers

## 1. What is `!important` in CSS?

`!important` is used to give a CSS property the highest priority and overrides normal CSS specificity rules.

---

## 2. Difference between `inline` and `inline-block`

An `inline` element does not start on a new line and cannot properly accept width and height values, whereas an `inline-block` element also stays in the same line but allows width and height to be applied.

---

## 3. Difference between `visibility: hidden` and `opacity: 0`

`visibility: hidden` hides the element and makes it non-interactive, while `opacity: 0` makes the element transparent but still clickable.

---

## 4. What are Media Queries?

Media queries are used to create responsive designs for different screen sizes such as mobile, tablet, and desktop.

---

## 5. What is the default position property?

The default value of the `position` property is `static`.

---

## 6. Types of Lists in HTML

HTML provides three main types of lists: ordered lists, unordered lists, and description lists.

---

## 7. What is `overflow: hidden`?

`overflow: hidden` hides content that exceeds the size of its container.

---

## 8. Difference between `img` and `figure` tag

The `img` tag is used only to display an image, whereas the `figure` tag is used to group images, captions, diagrams, or related content together.

---

## 9. Difference between Pseudo-class and Pseudo-element

A pseudo-class styles an element based on its state, whereas a pseudo-element styles a specific part of an element.

---

## 10. Difference between `align-items` and `align-content`

`align-items` aligns items inside a single flex line, whereas `align-content` aligns multiple flex lines when wrapping occurs.

---

## 11. How to create a dropdown menu

A dropdown menu can be created using HTML for structure and CSS or JavaScript to show and hide the menu items.

---

## 12. What is `z-index`?

`z-index` controls the stacking order of elements, where elements with higher values appear above lower ones.

---

## 13. What is Responsive Design?

Responsive design ensures that a website adapts properly to different screen sizes and devices.

---

## 14. CSS Color Formats

CSS supports multiple color formats such as color names, HEX, RGB, RGBA, and HSL.

---

## 15. How to get a new line in HTML

A new line in HTML can be created using the `<br>` tag or block-level elements.
